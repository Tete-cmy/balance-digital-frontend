# Balance Digital

Sistema web de finanzas personales desarrollado por Maximiliano Guerra Núñez.

## Descripción
Balance Digital es una aplicación diseñada para facilitar la administración y organización de las finanzas personales.

## Tecnologías
- React
- TypeScript
- Vite
- Node.js
- Express
- MySQL
- JWT

## Estructura del proyecto
Este repositorio contiene el frontend del sistema, desarrollado con React y TypeScript.

El backend se encuentra organizado en un repositorio independiente.

## Instalación
1. Clonar el repositorio.
2. Ejecutar `npm install`.
3. Configurar las variables de entorno necesarias.
4. Ejecutar `npm run dev`.
